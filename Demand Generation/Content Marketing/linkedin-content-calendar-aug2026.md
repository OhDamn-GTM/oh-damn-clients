## Status tracking

Update as each post moves through the workflow.

| Status | Meaning |
|---|---|
| Planned | Topic locked, not yet drafted |
| Drafted | Copy written, pending tone/persona + humanizer check |
| Approved | Passed self-check and humanizer, ready to schedule |
| Scheduled | Queued in LinkedIn/scheduler |
| Published | Live |

All posts below start at **Planned**.

Once a post is **Published**, run the first-60-minutes checklist (playbook Section 9), then track saves/comments/DM-shares (not likes) against it. If a post clearly resonates, log it as a recycling candidate (playbook Section 10) rather than letting it drop.
